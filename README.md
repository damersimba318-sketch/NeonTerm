# NeonTerm v1.0

Решил проверить, можно ли на пайтоне сделать свой терминал, чтобы он выглядел нормально (в стиле Linux Kitty), работал без вылетов и не весил при этом 50 мегабайт, как обычные поделки на customtkinter.

В итоге получился этот проект. Весит всего ~6 МБ, потому что собран через Nuitka в чистый C++.

## Что тут работает:
- Нормальный переход по папкам (`cd` не ломает путь самого скрипта).
- Команды запускаются в отдельных потоках, поэтому окно не виснет, когда открываешь `taskmgr`, `winver` или `msinfo32`.
- Ошибки процессов не крашат весь терминал.

## Как собрать самому в один .exe (6 МБ):
В репозитории лежит готовый `build.bat`. Но если запускать руками:
1. Ставим нуитку: `pip install nuitka`
2. Собираем: `nuitka --onefile --windows-disable-console neonterm.py`

Код открыт, забирайте и переделывайте под себя. Можете встроить вкладки, прозрачность. Короче делайте с ним чё хотите
